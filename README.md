# Dawn — 초간단 영상/음원 다운로더 (yt-dlp 기반)

**링크를 붙여넣고, 형식을 고른 뒤 다운로드.** 간결한 화면에서 영상과 음원을 저장합니다. Windows / macOS 지원.

둥근 병아리 캐릭터와 따뜻한 크림색 화면을 사용합니다. 앱 아이콘·상단 로고·빈 다운로드 목록에 같은 캐릭터를 적용하며, 작은 창에서도 형식 선택과 다운로드 버튼이 잘리지 않도록 구성했습니다.

## 다운로드 (빌드 없이 바로 사용)

[Releases](../../releases) 에서 받으세요:

| OS | 파일 |
|---|---|
| Windows x64 | `Dawn-windows-x64.zip` → 압축 해제 후 `Dawn.exe` 실행 |
| macOS Apple Silicon (M1~M4) | `Dawn-macos-arm64.zip` → `Dawn.app` |

> macOS 첫 실행: 앱 우클릭 → **열기** (미서명 앱 Gatekeeper 통과). ffmpeg·deno 내장.

| OS | 방법 |
|---|---|
| macOS | `Dawn.command` 더블클릭 (빌드 후엔 `dist/Dawn.app` 자동 실행) |
| Windows | `Dawn.bat` 더블클릭 (빌드 후엔 `dist\Dawn.exe` 자동 실행) |

첫 실행에만 가상환경+의존성 자동 설치 (인터넷 필요, 1–2분). ffmpeg는 내장 — 별도 설치 불필요.

## 기능

- **🎬 영상 + 음원**: MP4, 화질 선택 (최고/1080p/720p/480p), 제목·아티스트·날짜·설명·챕터 메타데이터 자동 삽입
- **🎵 음원만**: MP3 / M4A(AAC) / FLAC 선택 + 음질 옵션, **고해상도 정사각형 앨범아트**(YouTube maxres 우선 → 중앙 크롭) + 제목/아티스트/앨범 태그 자동 삽입
- **성인 인증·로그인 필요 영상**: 브라우저 쿠키 자동 사용 (Chrome/Edge/Firefox/Safari/Brave/Opera/Vivaldi/Whale) 또는 `cookies.txt`
- **재생목록 링크**: 감지 시 "전체 받기 / 이 영상만" 선택창 — "항상 전체 받기" 옵션으로 생략 가능
- **일부만 받기**: 시작~끝 시간 입력 (예: `0:30` ~ `2:15`)
- **자막 저장**: 한국어/영어 자동·수동 자막 `.srt` (체크 시)
- **중복 스킵**: 받은 항목은 이력으로 건너뜀 (재생목록 갱신에 유용)
- **클립보드 감시** (옵션): 링크 복사하면 자동 추가·다운로드
- **동시 다운로드**: 1~4개 병렬 처리 (`설정 → 다운로드`)
- **썸네일 미리보기**: 행에 영상 썸네일 자동 표시
- **완료 알림**: 시스템 트레이 토스트
- 여러 링크 한 번에 붙여넣기 (공백/줄바꿈 구분), 개별 취소, 진행률/속도/남은시간
- **DPI 검열 우회** (옵션): Windows는 GoodbyeDPI + WinDivert, macOS/Linux는 SpoofDPI. 별도 프록시 지정·기존 HTTP 프록시 자동 감지도 지원합니다.

## 사용법

1. 링크를 붙여넣거나 창으로 드래그합니다. 여러 링크도 한 번에 입력할 수 있습니다.
2. **영상 / 음원**, 화질·음질, **저장 위치**를 확인합니다.
3. **다운로드** 버튼 또는 링크 입력란에서 **Enter**로 시작합니다.
4. 완료된 항목의 **폴더 열기** 버튼으로 결과를 확인합니다. 목록 항목 더블클릭으로도 저장 폴더를 열 수 있습니다.

- **실수 없는 시작**: 기본값은 수동 시작입니다. 기존 방식은 `설정 → 다운로드 → 붙여넣은 링크 자동 다운로드`를 켜면 사용할 수 있습니다 (붙여넣기·드롭 후 0.7초).
- **설정 분류**: 다운로드 / 로그인 / 네트워크 탭으로 구분합니다. 자동 시작, 클립보드 감시, 자막, 구간 등 활성 옵션은 기본 화면에도 표시됩니다.
- **다시 시도**: 실패·취소된 항목에서 재시도할 수 있습니다. 긴 오류 메시지의 전체 내용은 마우스를 올려 확인합니다.
- **완료 항목 정리**: 완료·취소 항목만 목록에서 지웁니다. 파일과 실패 항목은 유지합니다.
- **키보드**: `⌘+L` (Windows: `Ctrl+L`)로 링크 입력란 이동, `⌘+V` / `Ctrl+V`로 붙여넣기.
- 저장 위치와 다운로드 옵션은 다음 실행에도 복원됩니다. 저장 폴더를 만들 수 없으면 링크를 유지하고 위치 변경을 안내합니다.

## 성인 인증 사용법

1. `설정 → 로그인` 열기
2. 로그인된 브라우저 선택 (예: Chrome에서 YouTube 로그인 상태)
3. **다운로드 중 해당 브라우저는 완전히 종료** (쿠키 DB 잠금 방지)
4. 또는 확장 프로그램으로 내보낸 `cookies.txt` 파일 선택

## DPI 검열 우회

`설정 → 네트워크 → DPI 검열 우회 사용`을 켠 뒤 다운로드합니다. 기본값은 꺼짐입니다.

| 운영체제 | 동작 | 권한·영향 범위 |
|---|---|---|
| Windows x64 | [GoodbyeDPI 0.2.2](https://github.com/ValdikSS/GoodbyeDPI/releases/tag/0.2.2) + WinDivert, 패킷 분할·UDP DNS를 1.1.1.1로 전달 | 관리자 권한 필요. 실행 중 다른 앱의 트래픽에도 영향을 줄 수 있음 |
| macOS / Linux arm64·x86_64 | [SpoofDPI 1.5.5](https://github.com/xvzc/spoofdpi/releases/tag/v1.5.5), localhost HTTP 프록시·TLS SNI 분할·1.1.1.1 DoH | 관리자 권한 불필요. Dawn 다운로드에만 적용 |

- **Windows**: 설정창의 **관리자 권한으로 다시 열기**를 누르고 UAC 요청을 승인합니다. 진행 중인 작업이 있으면 먼저 완료하거나 취소하세요. 권한 요청을 취소하면 기존 창이 유지됩니다. 초기 필터 확인에 약 21초가 걸릴 수 있습니다.
- Windows는 동시 작업들이 우회 프로세스를 공유하며 마지막 작업이 끝나면 종료합니다. macOS/Linux는 작업별 프록시를 종료합니다. 앱 종료 시에도 앱이 시작한 엔진만 정리합니다.
- 우회가 켜져 있으면 수동 프록시·자동 감지보다 우선합니다. 우회를 끄면 기존 프록시 설정을 다시 사용합니다. 프록시 탐색과 엔진 시작은 작업 스레드에서 처리합니다.
- 엔진이 없거나 시작하지 못하면 실패 이유를 표시합니다. 요청한 우회를 끄고 직접 연결하는 숨은 대체 경로는 사용하지 않습니다. 영상·음원과 앨범아트 요청에 같은 경로를 적용합니다.
- macOS/Linux에서 시스템 프록시 설정을 자동 변경하지 않습니다. 외부 SpoofDPI의 상태 파일이 감지되면 기존 설정을 건드리지 않도록 시작을 중단합니다. 별도 SpoofDPI를 정상 종료한 뒤 다시 시도하세요. 외부 인스턴스의 동시 시작은 피하세요.
- VPN이 아닙니다. IP 자체 차단, 계정·연령 인증, 유료 콘텐츠 접근 권한, 모든 ISP의 차단 방식에 대한 우회를 보장하지 않습니다. `geo-bypass`는 yt-dlp의 별도 옵션이며 DPI 우회와 다릅니다.
- macOS 우회 프록시를 통한 실제 HTTPS 연결을 확인했습니다. 릴리스 CI는 Windows·macOS의 패키지에서 우회 엔진 기동과 로컬 오디오 다운로드·변환을 검사합니다. 실제 ISP 차단 환경은 별도 확인이 필요합니다.

## 빌드 (배포용)

```bash
./build.sh                       # macOS -> dist/Dawn.app
# Windows (PowerShell/CMD):
#   .venv\Scripts\python scripts\fetch_bypass.py
#   .venv\Scripts\python -m PyInstaller dawn.spec --noconfirm   -> dist\Dawn.exe
```

우회 엔진은 **빌드할 때만** 공식 릴리스에서 내려받아 고정된 SHA256을 확인하고 라이선스와 함께 묶습니다. 앱 실행 중 엔진을 자동 다운로드하지 않습니다. Windows에서는 WinDivert 드라이버가 로드됩니다. 개발 환경은 `.venv/bin/python scripts/fetch_bypass.py`로 준비합니다.

빌드된 앱의 실제 오디오 다운로드·변환·엔진 기동 확인:

```bash
.venv/bin/python scripts/smoke_packaged.py --dpi-bypass
```

이 검사는 로컬 미디어를 사용하며 Windows에서는 관리자 권한이 필요합니다. 릴리스 CI에서도 실행합니다.

캐릭터 원본은 `dawn/mascot.svg`입니다. 수정 후 `.venv/bin/python scripts/render_icons.py`를 실행하면 화면용 PNG와 Windows ICO·macOS ICNS를 함께 다시 생성합니다. 앱에 반영하려면 이후 다시 빌드하세요.

## 구조

| 파일 | 역할 |
|---|---|
| `dawn/downloader.py` | yt-dlp 엔진, 쿠키, MP3/M4A/FLAC 태그+앨범아트, 영상 메타데이터, 클라이언트 재시도 |

| `dawn/bypass.py` | 운영체제별 우회 엔진 실행·종료·권한·동시 작업 관리 |
| `scripts/fetch_bypass.py` | 고정 버전 우회 엔진 및 라이선스 검증·설치 |
| `dawn/mascot.svg` / `scripts/render_icons.py` | 캐릭터 원본, 고해상도 이미지·플랫폼별 아이콘 생성 |
| `dawn.spec` | PyInstaller 빌드 정의 |
| `Dawn.command` / `Dawn.bat` | 원클릭 런처 |
